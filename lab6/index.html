Lab 6: Hierarchical GDP Treemaps

This lab visualizes a hierarchical GDP dataset using two different treemap segmentation strategies.

The hierarchy is: World → Continent → Area → Country . Rectangle area represents GDP, while color represents GDP status.

GDP Status Legend

1. Treemap — Squarify

Rectangle area represents GDP in billions of U.S. dollars. Color represents GDP status. Hover over a country for details.

2. Treemap — Slice-Dice

This view shows the same data using an alternating horizontal and vertical subdivision strategy.

3. Design Description

In both treemaps, rectangle area represents GDP because area provides a direct part-to-whole representation of quantitative values within the hierarchy. Countries with larger GDP values therefore occupy more visual space. GDP status is encoded with color because Increase, Unchanged, and Decrease are categorical states that can be distinguished efficiently without changing the spatial structure. Tooltips provide exact values and hierarchical context without overcrowding the visualization.

The first treemap uses the Squarify algorithm, which produces rectangles with more balanced aspect ratios and generally makes country labels and area comparisons easier to read. The second uses Slice-Dice, which alternates the direction of subdivision across hierarchy levels. This makes the parent-child structure more visually apparent, but some countries become long, narrow rectangles. Comparing the two views shows how tiling strategy changes readability even though the hierarchy and GDP values remain identical.
