Lab 4: Cleaning Web Data for Visualization

This visualization shows the distribution of model-estimated tweet sentiment across six U.S. airlines. Sentiment was calculated using a RoBERTa-based Twitter sentiment model.

Analysis

This project uses a public dataset of more than 14,000 tweets about six U.S. airlines. I cleaned the raw data by removing duplicate tweets, keeping valid tweet text, standardizing structured fields, converting retweet counts to numeric values, and parsing tweet timestamps. Sentiment was estimated from the tweet text using the RoBERTa-based twitter-roberta-base-sentiment-latest model. The model generated negative, neutral, and positive probabilities for each tweet, and the class with the highest probability was used as the predicted sentiment. The grouped bar chart compares the number of negative, neutral, and positive tweets for each airline. Overall, negative tweets are the most common sentiment category in the dataset. Some airlines also have noticeably different sentiment distributions, suggesting that customer reactions varied across airlines. These sentiment labels are model-generated estimates rather than ground-truth classifications.
