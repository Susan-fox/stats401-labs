Lab 5: Interactive Network Visualization

This lab explores a synthetic urban transit network using a force-directed node-link diagram and an adjacency matrix.

1. Dataset Description

This visualization explores a synthetic urban transit network containing 50 stations and 50 direct transit connections. Each station has a district, daily passenger volume, and station type. Each connection has a travel time and route type.

Node Encodings

  • Color: District
  • Size: Daily passengers
  • Shape: Station type

Link Encodings

  • Width: Travel time
  • Color: Route type

2. Node-Link Visualization

Hover over a station to highlight its direct connections. Drag a station to inspect the network structure.

3. Node-Link Design Description

In the node-link visualization, node color represents district because district is a categorical attribute and color makes geographic groups easy to distinguish. Node size represents daily passenger volume, allowing high-volume stations to visually stand out. Station type is encoded with shape so that local, transfer, and terminal stations remain distinguishable without relying on color alone.

For the routes, line width represents travel time, while route color distinguishes Metro, Express, and Shuttle connections. Hovering over a station highlights its direct neighbors and connected routes, while the tooltip provides detailed station information. Dragging allows the user to temporarily rearrange stations to inspect overlapping connections.

4. Adjacency Matrix

Rows and columns represent stations. Filled cells indicate direct connections.

5. Matrix Design Description

The adjacency matrix represents every station as both a row and a column. A filled cell indicates that two stations are directly connected. Cell color represents route type, while cell opacity represents travel time. Stations are ordered by district so that connections within and between districts form visible blocks in the matrix. Row and column label colors also indicate district membership.

This design makes dense connection patterns easier to inspect without the line crossings found in a node-link diagram. However, paths and the overall spatial topology of the network are easier to understand in the node-link view.

6. Network Questions and Findings

1. Which stations appear central in the network?

Well — Node-link visualization. Stations 31, 23, 7, 34, and 18 appear relatively central because they connect to several other stations and occupy important positions linking different parts of the network. This is easiest to see in the node-link diagram, where the number and arrangement of incident links reveal which stations have multiple direct neighbors. Hover highlighting also helps isolate each station's immediate connections.

2. Which districts are strongly connected to one another?

Well — Adjacency matrix, supported by the node-link view. The strongest inter-district connection appears between the East and South districts. Other strong connections are visible between Central and North, East and West, North and South, and Central and West. In the adjacency matrix, stations are ordered by district and label color shows district membership, so clusters of filled cells between district blocks reveal these patterns clearly.

3. Where are transfer or terminal stations located in the topology?

Well — Node-link visualization. Transfer and terminal stations are distributed throughout the network rather than being confined to one area. Their different node shapes make their locations easy to identify: circles represent terminals, squares represent transfer stations, and triangles represent local stations. For example, terminal stations such as Stations 7, 10, 25, 31, and 34 occur in several different parts of the topology, while transfer stations such as Stations 17, 26, 38, and 47 are also spread across the network.

4. Which stations have high passenger volume?

Well — Node-link visualization. Stations 50, 49, 48, 47, and 46 are among the highest-volume stations. Passenger volume is encoded by node size, so stations with larger symbols indicate heavier daily use. For example, Station 47 is visibly one of the larger nodes in the displayed network. The size encoding allows high-volume stations to stand out without requiring the viewer to read exact passenger counts.

5. Where are the longest direct travel-time connections?

Well — Both visualizations. The longest direct connection is between Station 7 and Station 31, followed by connections such as Station 18–34 and Station 29–50. In the node-link diagram, travel time is encoded by link width, so longer connections appear as thicker lines. In the adjacency matrix, travel time is encoded by cell opacity, which provides a second way to identify unusually long routes.

6. Are particular route types concentrated in particular parts of the network?

Partially — Both visualizations. There is some concentration, but the route types are broadly distributed across the network. Express routes appear frequently between Central–North, East–West, and Central–West stations. Metro routes are especially visible between East–South stations, while Shuttle routes also occur frequently between East–South and North–South stations. Route type is encoded by link color in the node-link diagram and cell color in the adjacency matrix, allowing these patterns to be compared across different parts of the network.
