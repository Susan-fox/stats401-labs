Lab 3: Web Data Acquisition

Dataset: Pokémon Records

Data Source: PokéAPI

Method: REST API using Python requests

Records Collected: 1,000

This dataset contains information about 1,000 Pokémon. Each record includes the Pokémon ID, name, height, weight, base experience, and type. The data was collected programmatically using Python and the PokéAPI REST API.
